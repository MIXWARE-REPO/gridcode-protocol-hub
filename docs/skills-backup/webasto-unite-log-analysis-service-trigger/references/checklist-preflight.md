# Checklist Preflight

- [ ] El cargador está identificado de forma unívoca.
- [ ] Hay edificio y plaza.
- [ ] La ventana temporal está definida.
- [ ] El log ZIP o la evidencia de descarga existe.
- [ ] Si faltan datos, hay bloqueo explícito y no se continúa.
- [ ] No hay defaults heredados de corridas anteriores.
- [ ] El input cumple el schema contractual.
- [ ] El destino de mail está confirmado solo si aplica.
